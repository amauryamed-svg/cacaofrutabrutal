# Skill: Caua Brand

Cuando el usuario pida diseñar, revisar o corregir cualquier componente visual de la app CAUA:

1. Lee `REFERENCE.md` para verificar colores, tipografía, voz y especificaciones de logo
2. Compara el componente actual contra los lineamientos
3. Identifica desviaciones específicas (color incorrecto, fuente incorrecta, tono de copia inadecuado)
4. Propone correcciones concretas con valores exactos de marca

**Invocar este skill para:**
- Revisar que un componente use los colores correctos (`#91A63B`, `#F1A91E`, `#8D2679`, etc.)
- Verificar jerarquía tipográfica (Acumin Pro / Gelica / Century Gothic y sus sustitutos)
- Auditar el tono de copy (motivating, inspiring, captivating — nunca "chocolate", siempre "cacao")
- Validar logo y uso de brand mark
- Revisar iconografía (line-based, orgánico, Pod Green)
- Evaluar layout (minimalista, espacio generoso, jerarquía bold)
