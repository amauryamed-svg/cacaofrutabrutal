## D2 — Safe multisig (TREASURY + PROTOCOL + admin)

Charter §I.3 requires a **2-of-2 Safe multisig** for treasury and protocol funds. CTO + CEO each hold one signer wallet.

### Setup

1. Visit https://app.safe.global/ on Base mainnet.
2. Each signer connects their own hardware-backed wallet.
3. Create a new Safe: threshold = 2, owners = [CTO_signer, CEO_signer].
4. Record the Safe address — it becomes both `TREASURY` and `PROTOCOL` recipient in `Deploy.s.sol`.
5. After deploy, **transfer DEFAULT_ADMIN_ROLE on all 5 contracts to the Safe**:
   ```solidity
   contract.grantRole(DEFAULT_ADMIN_ROLE, safeAddress);
   contract.renounceRole(DEFAULT_ADMIN_ROLE, deployerAddress);
   ```
6. Same with `PAUSER_ROLE` — Safe holds the pause emergency switch.

### Pre-handoff local audit (run before sending to vendor)

```bash

mythril analyze src/TreeAdoption.sol --solv 0.8.24 -o markdown > audit/myth-adoption.md
```

Resolve all `slither` HIGH + MEDIUM findings before vendor handoff. Document `slither` LOW + INFO with explanations in `contracts/audit/notes.md`.

## D4 — Phase 7 LP seed dry-run (Sepolia)

Before mainnet LP seed (Phase 7 Charter §I.5), dry-run on Sepolia to verify the 12-month timelock works.

### Steps

1. Deploy `LPTimelock.sol` to Sepolia from DEPLOYER wallet:
   ```bash
   forge script contracts/script/SeedLP.s.sol \
     --rpc-url $BASE_SEPOLIA_RPC \
     --broadcast \
     -vvv
   ```
2. Verify on BaseScan Sepolia: `LPTimelock.releaseTime() == deployTime + 365 days`.
3. Try `release()` from owner wallet → expect revert with `TimelockNotExpired`.
4. Use `cast --rpc-url $BASE_SEPOLIA_RPC call <LPTimelock> "releaseTime()"` to confirm.
5. Document result in `docs/SEED_LP.md` Phase-7 section.

### Mainnet LP seed (post-audit only)

Mirror the same flow with mainnet wallets + Uniswap v3 LP NFT. Timelock 12 months from `block.timestamp`, owner = Safe multisig.
